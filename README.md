# Roll-the-dice-dnd-v-
This is a small script that helps with quickly rolling damage the standard dice commonly used in D&D. Through further development, support for advantage and disadvantage on ability checks was added, and more recent versions allow for attack rolls and checking against Armor Class (AC).

If you would like to use this script, I recommend using the latest version (dice10_Vlad_eng v..py); it includes more features and has fewer bugs, and its also only one in English (the others are in Russian). The previous versions have been kept here to demonstrate code improvements - both for my own reference and for my portfolio.

Also, some files will have the note "Vlad v." attached; this indicates that this version was created together with my friend.
